# 0.3.6 - Game mode exp
<!-- generated:title:end -->

Might not be addressed this version, it will depend on the advancement of the project at that time.

Try new way to express the game mode. Maybe an extraction based game mode, where the player starts from a place and must rejoin that place to leave, instead of a pure time gate.

Once the time gate is passed, the player won't end the run right away but would start taking heavier and heavier damages. If he dies, he loses part of his score, so he must manage that properly, and can try to surf with the risk reward of the time gate.
