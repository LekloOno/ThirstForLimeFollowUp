## News

### Shield/Armor reduction icon

- [x] There's now a **UI icon** to show the player when he's **hitting special health** with reduction mechanism, that is more or less visible depending on the efficiency of such reduction on the received hit.
- [x] When a reduction **layer is broken through**, a **special icon** is also displayed.
- [x] This break icon is accompagnied with a distinct **sound cue**.

### Sector Icon, prediction & settings
- [x] Clean cross icon.
- [x] Add a **prediction UI**, so that the player can also know what will be the next sector.
- [x] Active sector's opacity and next sector's color are configurable in the **user's settings** (under accessibility settings).

### Ammos location UI helper
- [x] Add a UI helper that indicates **nearby ammunitions pickups** when the player is low on ammos.
- [x] Configurable in **user settings** - opacity and mode (disabled, display closest, display all)

## Fixes

### UI Kill skull offset delay

The skulls animation spawned on kills was not properly delaying its offset animation (moving the skull to the right of the screen after a short delay). The code was simply not waiting for any trigger before casting the offset event.
