# v-0.2.3 - minor update

## News

### Fists charge UI

There's now a UI element to show the current charge level of the fists, as well as if it is ready to shoot or not.

### Armor/Barrier sounds

Hitting an enemy with armor or barrier now produces a specific hit sound.

### Scores server status feedback

While waiting for the score API to respond, a little loading icon is now displayed.
Besides, if any error occurs while loading the scores, it is displayed in the scoreboard.

## Changes

### Hit sounds rework

Slightly reworked the sound design of hits and kill.

Besides, the kill sounds gets its pitch scaled with killstreaks.

### More intuitive wall climb

Wall climb can now be performed even with no prior speed, and even if the player is in a falling state.

When on ground with no speed, instead of the initial wallclimb hop, the player simply jumps.

### Pickup loader

The loading bar of the pickups is now a little brighter, to be a bit more visible.

## Fixes

### Slow mo loading ui

The loading UI of the slow mo pickup was synced with the damage buff pickup. It was simply not using its own view port texture.

### Windowed mode

Windowed mode was buggy, fighting against OS-level optimization. It should now work properly.

### Num inputs rounding

Numerical input tied to some settings editing would end up in a floating point mess when reacting to external changes. Now, it is smoothly rounded (purely visually, the value actual value remains unchanged).
