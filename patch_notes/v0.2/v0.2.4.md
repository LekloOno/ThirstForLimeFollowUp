# 0.2.4 - Client update for retro-compatibility
<!-- generated:title:end -->

This update is not a user-side thing. It's simply an update to the way scores are stored, to allow retro-compatibility.

Score have also been reseted, to clean up scores issued from different versions that were all mixed up.

Now, scores will be treated separately for each breaking change, and older version of the game will remain playable distinctively.

<!-- generated:toc:start -->
<!-- generated:toc:end -->

## Changes

### Scores per version

Scores are now tied to the version they were accomplished in, and leaderboard displays only the scores compatible to the client's version.  
Scores are thus not mixed up across breaking changes, while keeping older versions playable.
